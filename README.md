## Key Findings
- ShinyHunters operates a public extortion portal hosted on bulletproof infrastructure.  
- Infrastructure is linked to Prospero OOO (AS200593), a provider associated with cybercrime activity.  
- UNC6040 uses vishing and OAuth abuse to gain persistent cloud access.  
- UNC6240 handles extortion, data theft, and leak site operations.  
- Attackers leverage OAuth service principals to bypass MFA and maintain long‑term access.
